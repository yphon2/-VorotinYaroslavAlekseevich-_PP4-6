# LibraryApp

## Краткое Описание
Консольное приложение на C# для учета книг в библиотеке. Позволяет добавлять, выдавать и возвращать книги с проверкой на ошибки.

## Установка
1. Установите Visual Studio.
2. Откройте файл LibraryApp.sln. в Visual Studio.
3. Запустите проект (F5).

## Использование
Нажмите F5 в Visual Studio. Программа сама выполнит три тестовых сценария и выведет результат в консоль.

## Структура
Book.cs — класс книги.
Library.cs — логика библиотеки.
Program.cs — запуск и тесты.
TEST_REPORT.md — отчет об ошибках.

## Данные
Все книги хранятся в памяти (List) и сбрасываются при перезапуске.

## Лицензия
Приложение в рамках учебного проекта.
