# Отчёт о тестировании приложения LibraryApp

## 1. Объект тестирования
Консольное приложение LibraryApp, предназначенное для учета книг. Включает классы Book и Library.

## 2. Методика тестирования
Использовалось ручное тестирование и отладка с помощью точек останова (F9) и пошагового выполнения (F10) в Visual Studio. Также проводился статический анализ кода.

## 3. Найденные дефекты
В ходе отладки были проверены три сценария и выявлены следующие дефекты:

| ID | Описание | Шаги воспроизведения | Ожидаемый результат | Фактический результат (до исправления) | Статус |
| 1 | Исключение NullReferenceException при попытке выдать несуществующую книгу. | Вызвать метод lib.BorrowBook(99). | Вывод сообщения "Ошибка: Книга не найдена". | Программа аварийно завершается с ошибкой NullReferenceException. | Исправлен |
| 2 | Повторная выдача уже выданной книги. | 1. Выдать книгу: lib.BorrowBook(1). 2. Повторно вызвать lib.BorrowBook(1). | Вывод сообщения "Ошибка: Книга уже выдана". | Книга выдается повторно. | Исправлен |
| 3 | Изменение состояния невыданной книги при возврате. | 1. Вызвать метод lib.ReturnBook(2) для книги, которая не была выдана. | Вывод сообщения "Ошибка: Эту книгу не выдавали". | Программа без ошибок меняет статус книги на "Доступна". | Исправлен |

## 4. Результаты инспекции кода
В ходе статического анализа были выявлены следующие замечания:
1. Отсутствие проверок на null после поиска книги в списке.
2. Отсутствие проверки текущего состояния IsAvailable перед изменением.

## 5. Итоги
После внесения исправлений все три сценария работают корректно: программа не падает и выводит понятные сообщения об ошибках для пользователя. Качество кода улучшено за счет добавления проверок граничных условий.
